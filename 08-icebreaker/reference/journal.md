# 08 Icebreaker — журнал (v1)

Журнал живёт в общем хранилище артефакта (`db`). Его видят Кирилл и помощники с правом Contributor или выше. Выгружается в CSV.

## Документы

- `venues/<id>` — одно место: данные, бриф, находки, последние тексты и массив касаний `touches`.
- `stoplist/<id>` — контакт, который ответил «stop».
- `settings/ab` — активный тест в каждом канале.
- `reviews/<неделя>` — недельный разбор.

## Касание (`touches[]`)

| Поле | Что |
|---|---|
| `at` | когда отправлено |
| `mode` | after_visit, reply, recontact |
| `channel` | email, whatsapp, instagram |
| `variant` | сегмент (A/B), активный тест и его значение |
| `finding_type` | тип находки |
| `ask` | просьба |
| `delivered` | true, false или null (неизвестно) |
| `read` | true, false или null |
| `ig_part2` | вторая часть в Instagram отправлена |
| `replied` | true или false |
| `reply` | ответ дословно |
| `reply_type` | details, ask_owner, later, price, not_sure, no, other |
| `meeting`, `paid` | да или нет |
| `next`, `next_at` | следующий шаг и дата |
| `result_at` | когда записан результат |

## Экран «Сегодня»

- письмо отправлено больше 5 минут назад, доставка неизвестна → «Проверь, нет ли уведомления о недоставке»;
- Instagram, вторая часть не отправлена → «Приняли запрос? Отправь вторую часть с карточкой»;
- прошло 2 дня, результата нет → «Пришли скриншот переписки или отметь вручную»;
- прошло 3 дня, ответа нет → «Пора фоллоу-ап: новая находка»;
- наступила дата `next_at` → напоминание.

## Недельный разбор

Claude получает сводку журнала: счёт по каналам, вариантам и сегментам, ответы дословно. Он пишет по-русски:
- что сработало и насколько можно этому верить (при малом числе так и говорит);
- лучшие формулировки;
- какой тест запускать следующим.

Кирилл решает, что перенести в `playbook.md`.
