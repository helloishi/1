## 2. 10 паттернов, которые работают
1. **Одно окно по жизненным событиям** (LifeSG, TAMM, Tawakkalna): навигация по ситуации, не по ведомствам. Но у Tawakkalna работает за счёт обязательности и единой ID (уверенность С).
2. **Волонтёры-первые респондеры** (GoodSAM, PulsePoint, United Hatzalah, SGSecure): использование уже обученных людей рядом. Метрика успеха: включённые алерты, а не скачивания (Lincoln: 4 600 из 15 000).
3. **Единая маршрутизация обращений** (OneService, NYC311, FixMyStreet): гражданин не знает, чья это яма. Приложение сообщает «чья» и закрывает цикл. OneService: >2,5 млн обращений накопленно (2024).
4. **Многоязычные push-алерты для туристов** (Safety tips, Япония): 14–15 языков, инструкции «что делать».
5. **Открытые данные + краудсорс** (Wheelmap, Toilet Map, FixMyStreet): 1,5 млн мест на Wheelmap.
6. **Win-win локальная экономика** (Too Good To Go, Refill, Olio): экономия горожанину и прибыль заведению; Refill вырос с ~200 до >4 500 в Лондоне.
7. **Проактивность** (TAMM AutoGov): авто-продление лицензий вместо напоминаний.
8. **Once-only данных** (e-Estonia): не запрашивать одно и то же дважды.
9. **Открытый код и участие** (Decidim): повторное использование городами, офлайн-встречи + онлайн.
10. **Агентство платит, горожанин нет** (Transit): модель, где транспортные агентства спонсируют функции (+25% поездок у существующих пользователей, по заявлению компании).

## 3. 5 антипаттернов
1. **Лента страха и самосуд** (Citizen): награда $30 000, раскрытие адреса Billie Eilish, платные «агенты» ($19,99/мес).
2. **B2C-подписка поверх чужих сервисов** (Whim): банкротство 2024, €75,5 млн.
3. **Приложение без данных/бэкенда города** (Safe & the City, Streetwise, Soter): краудсорс без официальных данных не достигает критической массы (С, вывод аналитика).
4. **Сомнительная точность в чрезвычайной ситуации** (what3words): схожие слова, акценты; критика Mountain Rescue.
5. **Сообщить без обратной связи** (StreetSafe: пометки без публичных результатов; вывод: агрегированных результатов не найдено): подрывает доверие.
(Дополнительно: самоотчётные метрики без независимой проверки — Bonjour RATP 3 млн vs ~155 тыс. МАУ по сторонней оценке.)

## 4. ТОП-10 кандидатов на импорт в Лондон
(Оценка аналитика на основе найденного; «в Лондоне нет» проверено только по найденным источникам.)
1. **Единая «Report it» для всех 32 боро + TfL + Met** (OneService, NYC311, FixMyStreet): сейчас фрагментировано. Уверенность С.
2. **Офлайн-режим и «тур-режим» TfL Go** (жалобы: нет офлайна, нет загруженности): быстрый выигрыш, аудитория — туристы.
3. **Многоязычные push-алерты и инструкции «что делать» для туристов** (Safety tips): в Лондоне нет официального аналога по найденным источникам (Н, проверить).
4. **Карта доступности заведений (Wheelmap)** по Лондону, не только станций TfL.
5. **Живой реестр публичных и «community» туалетов + статус** (Toilet Map): 176 vs 18 по боро; официальный открытый набор данных.
6. **Проактивные городские услуги/напоминания** (TAMM AutoGov): продление разрешений, парковка, льготный проезд.
7. **Безопасные пешие маршруты на официальных данных** (Streetwise, Walkable, Soter показывают спрос): освещение, CCTV, ночные заведения от GLA/Met.
8. **Участие горожан (Decidim)** для бюджетов боро и приоритетов безопасности.
9. **Метрика «живых» алертов GoodSAM/AED-карта** (PulsePoint): публичная карта дефибрилляторов + CPR-обучение.
10. **«Один раз сообщить»: единая цифровая ID для услуг** (UAE PASS, Singpass, e-Estonia): политически сложно; частично (например, в рамках GOV.UK One Login — не проверялось).
