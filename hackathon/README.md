# London Civic Hack 2026

Хакатон о том, какие бесплатные приложения нужны жителям и гостям Лондона, причём такие, которые городские власти сочли бы по-настоящему полезными. Формат технический: исследование, затем банк идей, судейство, критика, работающие прототипы и Demo Day.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `00-brief.md` | Устав хакатона: правила, треки, аудитории, рубрика судейства |
| `research/01–06-*.md` | Шесть отчётов аналитиков: жалобы и медиа · туристы · опросы и статистика · аудитории и возрасты · отчёты компаний, рейтинги, будущее и политика · Product Hunt и госприложения мира |
| `ideas/pain-map.md` | Синтез: семь выводов и двенадцать главных болей |
| `ideas/idea-bank.md`, `idea-bank.json` | 72 идеи с доказательствами и оценками; `build_idea_bank.py` пересчитывает рейтинг |
| `ideas/critique.md` | Вердикт независимого критика (адвоката дьявола) |
| `apps/` | Пять прототипов (PWA) + общий дизайн-кит `apps/shared/` + регламент сборки `apps/BUILDING.md` |
| `pitch-en.md` | Одностраничный питч на английском для лондонских партнёров |
| `index.html` | Хаб на английском для GitHub Pages |
| `demo/` | Страница Demo Day (опубликована как артефакт) и скриншоты |

## Прототипы

| Приложение | Трек | Итог | Что делает |
|---|---|---|---|
| **Report It Right** (`apps/report-it`) | Город и я | 4,80 | Одна дверь: 20 ситуаций → нужный канал; SMS в BTP 61016; совет боро; быстрый выход |
| **PhoneGuard London** (`apps/phoneguard`) | Безопасность | 4,70 | Подготовка телефона, живая карта краж (police.uk), план «украли — первые 15 минут» на 6 языках |
| **London Ready** (`apps/london-ready`) | До поездки | 4,30 | ETA (официально или нет), трансфер из 6 аэропортов, contactless, чаевые, экстренная карточка |
| **Step-Free & Calm** (`apps/step-free`) | Передвижение | 4,30 | Лифты, план Б, загруженность и тихие часы для 509 станций |
| **Free London Today** (`apps/free-london`) | Бесплатный Лондон | 4,15 | 78 бесплатных мест «открыто сейчас», погода, вода, туалеты, библиотеки |

Все работают без регистрации, рекламы и трекинга. Основная часть доступна офлайн, живые данные (TfL, police.uk, OpenStreetMap, Open-Meteo, postcodes.io) запрашиваются прямо из браузера.

## Как запустить локально

```bash
cd hackathon && python3 -m http.server 8000
```

Откройте `http://localhost:8000/` (хаб) или `http://localhost:8000/apps/report-it/`.

## Как открыть на телефоне (GitHub Pages)

Репозиторий публичный, поэтому достаточно включить Pages: **Settings → Pages → Build and deployment → Deploy from a branch → `claude/optimistic-brown-m222fd` / `(root)`**. Через минуту прототипы будут по адресу `https://helloishi.github.io/1/hackathon/`, с живыми данными, геолокацией и установкой на главный экран.

## Вердикт жюри (кратко)

Независимый критик понизил все пять оценок и нашёл баг в плане Б: станции шли по алфавиту, а не по маршруту. Баг исправлен вместе с остальными замечаниями. Его рекомендация: первым нести мэрии **Report It Right**, PhoneGuard отдать Met без режима heads-up, Step-Free & Calm передать в TfL как функцию, London Ready оформить как контент для London & Partners, а Free London объединить с базовыми нуждами (вода, туалеты, тепло, еда). Подробности в `ideas/critique.md`.

## Перед пилотом

- В README каждого приложения есть список **To verify before launch**: телефоны, цены, пути в меню, переводы, форматы API.
- Исследование собрано по поисковой выдаче (прямое чтение сайтов было закрыто сетевой политикой окружения). Цифры помечены уверенностью, первоисточники перечислены.
- Внешние API не были доступны из среды сборки: парсеры проверены на синтетических примерах, которые в приложения не попали.
